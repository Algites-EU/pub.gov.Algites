Defines how an execution failure affects its parent execution hierarchy and the enclosing build.

Values:

FAIL_BUILD_ON_FAILURE: Requires the entire build to fail when this execution or any non-ignored descendant execution fails. This terminal failure cannot be absorbed by an ancestor execution policy. PROPAGATE_FAILURE: Propagates a non-terminal failure to the immediate parent execution, whose own BuildExecutionFailurePolicy decides whether to fail the build, continue propagation, or ignore the failure. IGNORE_FAILURE: Consumes a non-terminal failure at this execution boundary so that it is not propagated to an ancestor execution. An already terminal fail-build failure cannot be ignored.
