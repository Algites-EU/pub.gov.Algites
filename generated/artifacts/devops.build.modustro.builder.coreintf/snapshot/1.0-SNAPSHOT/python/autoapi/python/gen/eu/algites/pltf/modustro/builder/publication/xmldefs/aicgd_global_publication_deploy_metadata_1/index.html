global_publication_path_id¶

Stable logical publication path copied from validated user metadata.

publication_state¶

Server-controlled publication lifecycle state. Released definitions are immutable and cannot transition back to draft.

publication_revision¶

Server-controlled monotonically increasing revision of successfully deployed draft content. Release freezes the current content revision.

first_published_at¶

Server-generated timestamp of the first successful deployment for this GlobalPublicationPathId.

published_at¶

Server-generated timestamp of the most recent successful deployment or release transition represented by this metadata.

released_at¶

Server-generated timestamp at which this publication became an immutable release; absent while the publication is a draft.

published_by¶

Optional trusted publisher identity derived by the deployment adapter from authenticated execution context; never copied from user metadata.
